# 🧹 SmartClean - Professional Data Cleaning Tool

A powerful web app to clean your data files easily!

---

## 🌐 Live App
👉 [Click here to use SmartClean](https://smart-cleaner-file-adi.streamlit.app/)

---

## ✨ Features

### 1. Smart Ingestion Engine
- Upload CSV, Excel, JSON files
- Auto detects file format
- High performance parsing

### 2. Auto Profiling & Schema Check
- Dataset health score
- Visual data summary
- Column wise analysis
- Missing value charts
- Outlier detection

### 3. Clean Machine
- Remove duplicate rows
- Handle missing values (Median/Mode/Drop)
- Clip outliers (IQR Method)
- Text sanitation
- Date standardization (ISO Format)

### 4. Export Engine
- Download as CSV
- Download as Excel
- Download as Parquet (ML ready)
- Download PDF Report
- Download Excel Report
